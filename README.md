# Minasis Dalamud Plugins

Minasis（GitHub: [minasis-min](https://github.com/minasis-min)）のプラグインをまとめて配布するカスタムリポジトリです。

Dalamud設定のカスタムプラグインリポジトリへ、次のURLを追加してください。

`https://raw.githubusercontent.com/minasis-min/Minasis-Dalamud-Plugins/main/pluginmaster.json`

| Plugin | Source / releases |
| --- | --- |
| Plugin Chat Overlay | [PluginChatOverlay](https://github.com/minasis-min/PluginChatOverlay) |
| Tooltip Extras | [TooltipExtras](https://github.com/minasis-min/TooltipExtras) |

各プラグインのソース・配布ZIP・対応環境・ライセンス・AI利用範囲は、それぞれのリポジトリを参照してください。不具合は対象プラグインのIssuesへ報告してください。
