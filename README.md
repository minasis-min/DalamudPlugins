# Minasis Dalamud Plugins

Minasis（GitHub: [minasis-min](https://github.com/minasis-min)）のプラグインをまとめて配布するカスタムリポジトリです。公式Dalamudリポジトリへの登録は行っていません。

Dalamud設定のカスタムプラグインリポジトリへ、次のURLを追加してください。

`https://raw.githubusercontent.com/minasis-min/DalamudPlugins/refs/heads/main/pluginmaster.json`

| Plugin | Source / releases |
| --- | --- |
| Plugin Chat Overlay | [PluginChatOverlay](https://github.com/minasis-min/PluginChatOverlay) |

開発版を使用していた場合は、先に無効化してからインストールしてください。初回のカスタムリポジトリ経由でのインストール確認は、公開後に作者が行います。

各プラグインのソース・配布ZIP・対応環境・ライセンス・AI利用範囲は、それぞれのリポジトリを参照してください。配布ZIPは各プラグインのGitHub Releasesに掲載し、このリポジトリには保存しません。

今後のプラグインは同じ `pluginmaster.json` の配列へ追加します。既存エントリーを保持し、同じInternalNameを重複させない運用とします。不具合は対象プラグインのIssuesへ報告してください。
